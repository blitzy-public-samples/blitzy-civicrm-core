Why Now

The driver

AngularJS is end-of-life

1.8.2 AngularJS version in use today
Jan 2022 End-of-life since this date
  • No security or compatibility fixes ship for AngularJS 1.8.2.
  • .aff.html markup is declarative and framework-agnostic, which lowers migration risk.
